API
POST /api/auth/signup { name, email, password } → free plan, 20 credits, set cookie
POST /api/auth/login { email, password } → set cookie
POST /api/auth/logout → clear cookie
GET /api/me → { user, brand } or 401
POST /api/brand → upsert brand
GET /api/generations → newest first
PATCH /api/generations { id, status, scheduledFor }
POST /api/plan { plan }
POST /api/generate/post { topic, platform } → caption + image
POST /api/generate/image { brief, style } → still
POST /api/generate/reel { topic } → title, hook, 4 beats, caption, voiceover + four 9:16 images 720x1280
POST /api/generate/calendar { days } → 5–14 scheduled posts, default 7
POST /api/generate/reply { text, channel, from, kind } → draft + save message
POST /api/generate/ad { offer, platform } → copy + square image
POST /api/generate/website → HERO/ABOUT/OFFER/PROOF/VISIT/CTA + hero image

Every generate route: require session, check credits, inject brand into the prompt, deduct credits, save generation, return { item, credits } or { items, credits }.
Return Pollinations image URLs. Do not store binary files.
